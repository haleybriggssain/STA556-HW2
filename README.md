Project Purpose: Analyze data on 500 languages involving their language family, region, writing system, and number of speakers.

Data Source: 500x6 DataFrame where each row is a different language and each column contains data on the language.

How to Run: The analysis is completed in the notebook file 'homework2.pynb'. Everything needed to run through the analysis is available there. The code chunks should all be ran in the order provided. Three figures can be found in the 'figures' folder, and the three functions that are used can be found in the 'functions.py' file in the 'src' folder. The original data is found in the 'data' folder. There is no processed data because the analysis did not call for it.

Main Finding: The majority of languages have less than 100,000,000 speakers, but there is a strong right skew because few languages have far more speakers. Additionally, the Latin writing system is used far more than any other writing system. 208 languages utilize the Latin writing system while the next most common is Devanagari with only 28.
